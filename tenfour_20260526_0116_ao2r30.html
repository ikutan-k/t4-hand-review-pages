T4 HAND REVIEW

BB 5♥5♣ の UTG open defend / flop check-raise レビュー

GTO基準では、UTG 2BB openにBBで 5♥5♣ をcallするところは自然です。大きなズレはflop T♠ 7♥ 6♥ のcheck-raiseで、55 はここでOESDではなく、set outsと薄いバックドアに近いハンドです。turn以降の大きいbarrelはラインとしては一貫していますが、flopで選ぶブラフ候補が薄いため、全体としては攻めすぎ寄りです。

Hero: BB 5♥ 5♣
Villain: UTG A♦ K♥
Board: T♠ 7♥ 6♥ 3♥ 6♣
  • 主要論点: BB defend後、T♠ 7♥ 6♥ のUTG large c-betに対して 5♥5♣ をcheck-raiseから3街打ち切ってよいか。
  • GTO基準の総評: preflop callは良いです。flop check-raiseは、BB側にtwo pair / set / straight drawが多いboardなので戦略としては存在しますが、55 はその中ではかなり薄い候補です。
  • 次回の判断基準: T76 系でcheck-raise bluffを作るなら、pair + straight draw、強いheart draw、54s / 85s のようにturn以降も自然にbarrelできるハンドを優先します。
  • 5枚役確認: River時点のHeroは 6♥ 6♣ 5♥ 5♣ T♠ のtwo pairですが、value betできる強さではなく、65.05BB は実質bluffです。

持ち帰り

  • T76 で 55 を持った時、見た目よりdrawが弱いです。1枚の4や8でstraightになるわけではないので、flop check-raise候補としては下げます。
  • BB側に強いrangeがあるboardでも、ブラフ候補は無制限に増やしません。callされた後にturn / riverで自然に圧をかけられるcomboを選びます。
  • Riverでtwo pairになっていても、相手のturn call rangeに勝てるかを先に見ます。今回はvalueではなく、相手の中強度を降ろすbluffとして整理します。
  • 今回のラインは成功していますが、標準形としては 55 のflop check-raise頻度をかなり下げ、より強いdrawやpair + drawに寄せる方が安定します。

exploit 補足

  • 実戦のUTGは A♦K♥ で、flop large c-bet後にcheck-raiseをcallし、turnもA-high + K-high heartで続行してriver foldしています。このようにovercard + heart blockerで広く残り、riverで降りる相手には、BBの大きいbarrelは利益を持ちやすくなります。
  • ただし、riverの実戦相手はHeroがcheckしてもかなり勝てるA-highです。結果だけでラインを正当化せず、標準では 55 よりもequityとblockerが強いcomboをbluffに回します。
