T4 HAND REVIEW

CO J♠T♠ の 3bet pot river straight value レビュー

GTO基準で、CO J♠T♠ の 2.3BB open と、SB 10BB 3bet への call は自然です。flop K♠ 7♣ 3♥ の 1/3 c-bet call は、pair も直接のstraight drawもないためやや薄いですが、IPで backdoor flush / backdoor straight を持つので許容範囲です。良かったのは、turn 9♦ で open-ended straight draw になった後に小さくbetし、river 8♦ で straight 完成後に 39.38BB と大きく value を取り切った点です。SB の AA/AK/KQ から十分に取れるため、river の大きめbetは良いです。

Hero: CO J♠ T♠
Villain: SB A♠ A♦
Board: K♠ 7♣ 3♥ / 9♦ / 8♦
  • GTO基準の総評: preflop は良く、flop call はやや境界、turn 以降の攻め方は良いです。
  • このハンドの主要論点: 3bet pot の K-high board で、backdoor だけの flop call をどこまで残すか。
  • 一番大きい改善ポイント: flop call は「two broadwayだから」ではなく、IP・小サイズ・backdoor equity が揃う時だけに絞る。
  • river value はかなり良いです。JTs はこの board でnutsなので、SB の overpair / top pair から大きく取りにいけます。

持ち帰り

  • JTs はCO open後、SB 3betに対してIPでcallしやすい hand です。preflop は良いです。
  • K-high 3bet pot の flop call は、pairなしならかなり選別します。今回の続行理由は小サイズ、IP、backdoor spade、turn改善カードがあることです。
  • turn で open-ended になったら、check backで無料実現するだけでなく、小さくbetして fold equity と river equity を両方使えます。
  • river で JTs がstraightを完成したら、この board ではnutsです。SBのoverpair / top pair から大きく取ります。

exploit 補足

  • 実戦のSBは A♠A♦ で、turn check-call、river large bet call まで進んでいます。overpair を降りにくい相手には、今回のような river 大きめvalue がかなり有効です。
  • 一方で、flop float を広げすぎると、turnで改善しない時に苦しくなります。利益の中心は「薄いflop call」ではなく、「改善した時にしっかり value を取り切る」部分です。
