T4 HAND REVIEW

HJ A♣6♣ の BB donk start / river bluff raise レビュー

GTO基準では、flopの A♣6♣ OESD callは良い判断です。一方で、turnの75% potに対するcallは下限寄りで、riverのbluff raiseは候補になりますが、サイズが小さめなので「何を降ろすraiseなのか」をはっきりさせたい場面です。

Hero: HJ A♣ 6♣
Villain: BB A♥ 9♠
Board: 8♥ 7♠ 5♦ 3♣ Q♣
  • 主要論点: HJ open後、BBの 8♥ 7♠ 5♦ donkから3発目まで受け、missed OESDでriver raise bluffしてよいか。
  • GTO基準の総評: BBのdonkは 8x やsetだけでなく、straight、two pair、pair + draw、9x/6x系のsemi-bluffまで含めて読む必要があります。Heroのflop callは良いですが、turn callは「OESDだから自動call」ではなく、BBが十分にbluffを残す前提が必要です。
  • 次回の判断基準: Riverでmissed drawをraiseに回すなら、相手のfold対象が A high / 9x missed なのか、8x / overpair相当 / set なのかを分けます。後者まで落としたいなら、今回のサイズはやや安く見えます。
  • 5枚役確認: River時点のHeroは A♣ Q♣ 8♥ 7♠ 6♣ のhigh cardです。BBが A♥9♠ でcallすると A-Q-9-8-7 になり、Heroは負けます。つまりriver raiseは純粋なbluffです。

River Q♣BBが約87% potで3発目を打っています。QはBBの低連結valueをあまり増やさず、HJ側のoverpair/QQ/Qx表現には使いやすいカードです。Heroはmissed drawで、callしてもA9oに負けます。6 blockerがあるためbluff raise候補にはなります。exploit寄りに良いraise自体は良い発想です。ただしこのサイズはA-highやmissed drawを降ろすには十分でも、強いmade handを降ろすには安めです。

持ち帰り

  • Flop callは良いです。8♥7♠5♦ のBB donkに対して、A6sのOESDは十分に続行できます。
  • BB donkの理由を 8hit / set に絞ると狭すぎます。このboardではBBにstraight、two pair、pair + draw、9x/6xのsemi-bluffがかなりあります。
  • Turn callは自動ではありません。75% potに対して、A-high OESDだけでcallするには、相手がA9oのようなhigh-card/gutshotまで打つ読み、またはriverで攻め返せる計画が必要です。
  • Riverの Q♣ は完全なラグではなく、HJ側が強く見せやすいカードです。missed A6sはbluff candidateとして自然ですが、valueを降ろすつもりならもっと大きいpolar sizeが必要です。
  • 今回のraiseは、実戦の相手がA-high missed drawで3発目を打っていたため、exploitとしては成功しています。ただし相手がset/straight中心でcallを多くするタイプなら、riverはfoldが標準寄りです。

exploit 補足

  • 実戦のBBは A♥9♠ で、preflop defendもpostflopの3発目もかなり広めです。このタイプがA-high/gutshotをriverまで打って、raiseに降りるなら、Heroのmissed draw raiseは利益的になります。
  • 逆に、BBがriver bet後にone pair以上をあまり降ろさない相手なら、今回のraise sizeでは十分なfold equityを取りにくいです。その場合は、turnで下限callを減らすか、riverはより大きいpolar raiseに絞ります。
